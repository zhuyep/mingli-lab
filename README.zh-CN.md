# 明理 · Bazi Lab

**看得见推演过程的八字实验室。改一个口径，看一张盘为什么变。**

[English](README.md) · [计算口径](docs/method.md) · [参与贡献](CONTRIBUTING.md) · [MIT 许可](LICENSE)

![明理排盘界面](docs/images/desktop.png)

无需账号、无需 API Key、生日不上传。打开就是一张可以点击、对照和复算的四柱命盘。

> 当前为 0.1.0 发布候选：本地代码与演示已就绪，公开仓库、线上演示和真实用户采用尚未核验。

## 一分钟体验

需要 Node.js 22.12 或更高版本。从项目目录运行：

```sh
npm ci
npm run dev
```

打开终端给出的本地地址。先点「月柱」，看戊为什么相对辛称为正印；再点「23 点，会换一天吗？」，比较同一时刻两种子时口径的结果。不必先填写自己的生日。

## 首版能做什么

| 功能 | 你能看到什么 |
| --- | --- |
| 公历排盘 | 四柱、藏干、天干与藏干十神 |
| 点击一柱 | 日干 → 五行关系 → 阴阳 → 十神名称 |
| 子时对照 | 00:00 和 23:00 换日引起的日柱与关系变化 |
| 已有八字 | 支持四柱；时辰未知时只填前三柱 |
| 五行与关系 | 显性字位计数、六冲、六合、六害、完整三合组合、日柱旬空 |
| 大运 | 可选传统顺逆公式；日期输入用历法库的分钟折算起运法 |
| 导出 | 本地 SVG 命盘卡片和含完整输入的 JSON |
| 移动与国际化 | 手机适配、中英切换、键盘操作、无远程字体 |

这里的解释是传统规则的结构说明，不自动选用神，不生成吉凶分数，不把五行计数当作力量，更不据此判断人的疾病、投资或婚姻结果。首版不包含住宅风水、紫微斗数或模型聊天。

## 为什么需要看清口径

同一个 **1988-02-15 23:30（UTC+8）**：

| 换日规则 | 年柱 | 月柱 | 日柱 | 时柱 |
| --- | --- | --- | --- | --- |
| 00:00 换日 | 戊辰 | 甲寅 | 庚子 | 戊子 |
| 23:00 换日 | 戊辰 | 甲寅 | 辛丑 | 戊子 |

两者的晚子时时干都按次日日干推，日柱却不同。十神是相对日干的关系，所以名称也会变。明理把这些差别摆在一起，供学习和复核。

## 开发者使用

```sh
npm run chart -- --date 2005-12-23 --time 08:37
npm run chart -- --pillars "乙酉 戊子 辛巳"
npm test
npm run build
```

纯 JSON 输出、TypeScript 接口与参数说明见 [英文 README](README.md#use-the-calculation-core)。仓库包含静态网页与独立计算核心，不是已发布的 npm 包。GitHub Actions 已配好测试与构建；Pages 采用手动部署。见[部署说明](docs/deploy.md)。

## 边界与依据

- 公历输入支持 1901–2099 年，按东八区标准时（固定 UTC+8）。不自动处理出生地时区、历史夏令时、真太阳时或农历输入。
- 手动输入只检查干支字对，不能证明整组四柱对应真实历法时刻；未知时辰不补造时柱或大运。
- 采用 [lunar-typescript 1.8.6](https://github.com/6tail/lunar-typescript) 的历法与藏干表，保留 MIT 许可；测试验证实现一致性，不证明命理预测有效，也不是独立天文精度认证。
- 生辰只参与本地计算，应用不写浏览器存储、不调用远程分析接口。卡片省略原始生日，但四柱仍可能涉及隐私；完整 JSON 要自行保管。
- 已加载页面可继续本地计算；首版没有离线缓存，不承诺断网后首次打开或刷新可用。
- 项目使用原创界面与说明，不附讲稿 PDF、全文转写或个人生平案例，也不以任何讲者名义背书。
