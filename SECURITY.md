# Security and privacy reports

Do not include real birth data, API keys or credentials in a public issue. A minimal synthetic reproduction is enough. If private vulnerability reporting is enabled on the hosted repository, use its Security → Report a vulnerability entry. Otherwise open an issue requesting a private contact route, without exploit details or personal data.

There is no backend, account database, model provider or API key field in this release. The app processes input in memory and creates downloads only on request. Dependency and HTML-injection issues are in scope. Predictive claims about personal fate are not security findings; this software does not validate those claims.
