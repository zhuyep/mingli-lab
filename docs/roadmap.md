# Roadmap

## Public preview 0.5.0

Implemented: black-and-white hand-drawn interface, self-hosted handwriting font, six separate bilingual domains with questions and visible chart evidence, independent sleep check-in, adjacent-year comparison, month/roots/exposure, candidate balance paths, dated annual/cycle relationships, local guided questions, Markdown/SVG/JSON exports, and the original calculation appendix. Public source and hosted demo are live; independent use remains a separate validation step.

## Next only when a real use case supports it

1. Professional review of the published interpretation heuristic and real-user completion feedback.
2. An independently sourced boundary fixture set, including solar terms and historical clock conventions.
3. Better English terminology and screen-reader feedback from actual users.
4. A carefully specified timezone / DST input flow, with ambiguous-hour handling, before considering global births.
5. Optional local-model explanations limited to structured facts, if users can show what deterministic explanations cannot answer.

Not planned for the initial release: fate scores, lifespan or disease forecasts, investment timing, chart compatibility judgments, scraping birth records, paywalls, cloud accounts or a sprawling collection of divination systems.

Please report a task you could not finish before requesting more features. A screenshot or a fixture with expected behavior is more useful than an unsupported claim of accuracy.
