# Design intent

An interactive desk for curious BaZi learners and developers: change an input, inspect the rule, reproduce the result.

Palette: porcelain `#f5f8fc`, ink `#172d49`, blue glaze `#254d85`, celadon `#468176`, ochre `#a07537`, muted slate `#63748a`. Display: restrained local Songti/Noto Serif CJK serif for Chinese characters; system sans for controls; local monospace for timestamps. No remote font requests.

Layout: a compact introduction above a working desk. Input notebook on the left, four large interactive pillar slips on the right; explanation beneath. On mobile the notebook precedes the four-column chart. All essential controls work by touch and keyboard.

Signature: select one pillar and expose the relative ten-god calculation beneath it. A separate Zi-hour comparison shows how a convention changes the same input, rather than depicting a made-up luck curve.

Plan critique: a mystical dark dashboard or parchment fortune scroll would imitate the category without clarifying it. Porcelain blue, a visible calculation trail and generous character spacing make this an instrument for learning. Decoration is limited to the five-phase cycle; no animated particle effects.
