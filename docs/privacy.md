# Privacy / 隐私

The application does not use analytics, cookies, browser storage, remote fonts, cloud models or background API calls. Form values exist in JavaScript memory. Reloading resets application state; browser-managed form behavior is outside this guarantee. Opening a hosted app requests its static files and the hosting provider may log ordinary network metadata.

Selecting an external source link leaves the app. No form values are placed in links or URL parameters. Downloaded JSON contains the input date, time and traditional formula selection; Markdown readings and SVG cards omit those raw details but retains the pillars and convention. Pillars may permit inferences about a birth timestamp: **omitting a date is not anonymization**.

Use teaching examples when sharing screenshots or reporting issues. The release package contains only reference/example inputs, never user birth records. The app provides no upload/import feature in this release and does not send exports anywhere.

中文：应用内不保存、不上传生辰，也不接入云端模型。静态托管服务仍可能记录访问元数据。JSON 包含原始输入与解读；Markdown 命书和 SVG 省略原始生日，但四柱仍可能涉及隐私。公开截图和问题报告请用教学例子。

Optional sleep responses remain only in page memory. They do not enter the chart object, Markdown, SVG or JSON exports. Opening a new chart resets them. Responses are never sent to the linked CDC site.

选填睡眠回答只在当前页面中使用；新开命盘时重置，不进入任何下载文件，也不会传给来源网站。

Optional work, money and relationship choices are held only on the current page and reset with a new chart. Unlike sleep responses, selected action plans are included when you explicitly download Markdown or JSON. SVG does not include these choices. No choice is sent to a source site.

工作、金钱、感情的选项只留在本页；选择保存 Markdown/JSON 时会带上已选做法，新命盘会清空选项。SVG 不带这些选项；睡眠回答仍不进入任何导出。
