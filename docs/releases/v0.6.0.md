# 天机簿 v0.6.0 · 专业说法，说给人听

根据用户补充意见，每章按“专业说法 → 大白话解释 → 生活例子 → 可以试的做法”展开。保留命理用语，但不再要求读者先读懂藏干、宫位和制化，才能理解正文。

例如“食伤与财星并见”后会解释本事、需求与收入的关系，再以接设计单为例，说明先问用途和预算、先看草图再做整套的顺序。工作、钱与收入、感情各有不同例子。

新增九个可选困扰：忙却没成果、做事没人看见、考虑换工作、不知钱花哪里、等待付款、合作接活、总为小事吵架、难说出需要、单身想认识人。每个选项给出三步做法、一句示例话和做完后的检查点。困扰由用户选择，不能从生辰推定。

年度对照也改用短句解释。完整命理事实与边界仍可展开查看。选中的做法会随 Markdown/JSON 保存；作息回答不保存、不导出。全部计算与交互仍在本地完成。

## English

Each chapter now shows a short traditional term, a detailed plain-language explanation, an everyday example and optional practical steps. Nine selectable situations provide three steps, a sample phrase and a check afterward. Situations come from the user, never from birth data. Selected plans appear in Markdown/JSON exports; sleep responses remain excluded.

The calendar and traditional topic-selection rules are unchanged. This revision improves the presentation and makes suggested actions inspectable; it does not establish predictive accuracy or proven user benefit. Rule tests and browser checks are recorded with the delivery.

See [method and references](../reading-method.md) for the distinction between traditional analogies and everyday action suggestions.
