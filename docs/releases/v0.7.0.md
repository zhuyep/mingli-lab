# 天机簿 v0.7.0 · 先看风格，再谈调整

v0.6 把“这类命盘的风格”和“可以怎么做”混在一起，建议句被当成分析标题。本版把两者拆开：

- **命理倾向分析**：先专业说法，再用白话说明风格、可能的长处和卡点。
- **调整建议**：独立标题与区域；说明什么情况下适用，再给改法和例子。
- **你填写的现状**：九种困扰默认收起且不预选，主动选择后才作为自述，匹配步骤另列。
- **整体风格与年份**：整体页先给风格概括；年份先描述传统话题，再单列建议。
- **导出一致**：Markdown 和 JSON 同样拆开分析、建议和已选现实情况；睡眠回答不导出。JSON 阅读版本变为 `tianji-rules-2-analysis-advice-1`。

38 项规则测试通过；黑白手绘和原有历法计算保留。命理倾向属于传统符号的现代类比，不是已核实的性格或生活现状；可读性的实际改进仍待用户体验。

## English

The previous reading placed suggestions where a reader expected a description. This release separates **symbolic analysis**, **conditional suggestions** and **self-reported context**, in both the interface and exports. Style, possible strengths and friction come first; examples of actions to try sit in a separate suggestion section. Optional situations are collapsed and never selected from a chart. Nearby years show descriptive themes before any advice.

38 rule tests pass. Calendar calculations are unchanged. The analogies are not measured traits or confirmed life circumstances. Export consumers should check the new reading version.
