# 天机簿 v0.8.0 · 把命理展开讲清楚

过去每个方向只有短结论，缺少术语、依据和条件之间的推理。本版在六章中加入 16 个展开小节，古籍短引、白话解释和本盘字位一起可见，调整建议仍单独呈现。

- 工作：八种组合分别解释，例如食伤生财中的能力、交付与需求，以及为何不能直接认定成格。
- 财务：正偏财、透藏、生财与承财分开说明，十神配对随日主变化。
- 感情：夫妻宫、配偶星、日支本气与实际合冲位置分开，合冲并存不会互相删掉。
- 整体与年份：月令、根气、透干、强弱，以及原局、大运、流年的层次和逐年变化。
- 健康：解释调候、偏枯等传统词义，实际作息提示仍只来自填写的情况。
- 八则古籍短引均可点击核对，注明录文来源；现代类比不冒充古籍原意。Markdown 保留短引与链接，JSON 同带出处目录。

验证：46 项规则与导出检查通过；浏览器核验见交付记录。命理计算口径未改，测试不证明预测有效，内容是否满足阅读需求等待用户反馈。
